# VendaFácil MZ — Landing Page

Página de vendas independente do aplicativo VendaFácil MZ.

## Estrutura
- `index.html` — página de vendas
- `styles.css` — design responsivo
- `script.js` — configuração do checkout

## Checkout
Quando o checkout EscalePay estiver disponível, abra `script.js` e substitua:

`const CHECKOUT_URL = "";`

pelo URL real do checkout.

A página não contém um URL de pagamento inventado.
